# Чек-лист проверки флоу регистрации на мобильной версии

**Дата:** 28 апреля 2026  
**Платформа:** iOS/Android  
**Версия приложения:** 3.2.1

---

## 📱 1. СТРАНИЦА ЛОГИНА/РЕГИСТРАЦИИ (/login)

### Базовая доступность
- [ ] Страница загружается за < 3 сек
- [ ] Нет ошибок в консоли браузера (F12)
- [ ] Нет горизонтального скролла
- [ ] Все элементы видны без zoom

### Визуальный дизайн
- [ ] Форма центрирована и читаемая
- [ ] Иконки и текст имеют достаточный размер
- [ ] Цвета контрастные (ссылки, кнопки, текст)
- [ ] Фоновый градиент отображается корректно
- [ ] На iPad форма выглядит правильно (не растянута)

### Переключение между Sign In / Sign Up
- [ ] На странице видна ссылка на Sign Up (или переключатель)
- [ ] Клик на "Sign Up" переводит на `/login?signup=true`
- [ ] Форма переключается корректно (смена стиля/цветов)
- [ ] На форме Sign Up видна ссылка вернуться на Sign In

## 🔐 2. ФОРМА РЕГИСТРАЦИИ (Sign Up)

### Поля ввода
- [ ] **Email поле:**
  - [ ] Placeholder текст видим
  - [ ] Размер поля достаточен (не менее 44px высоты)
  - [ ] Keyboard тип = email (на мобильном)
  - [ ] Автодополнение почты работает (iOS/Android)

- [ ] **Password поле:**
  - [ ] Placeholder текст видим
  - [ ] Размер поля достаточен (не менее 44px высоты)
  - [ ] Пароль скрыт точками (на Sign Up)
  - [ ] Есть кнопка toggle show/hide password
  - [ ] Toggle работает корректно (показывает/скрывает текст)

### Валидация в реальном времени
- [ ] При вводе некорректного email показывается ошибка
- [ ] При пустом пароле показывается ошибка (если требуется)
- [ ] Ошибки исчезают при введении корректных данных
- [ ] Ошибки видны и читаемы на мобильной версии
- [ ] Нет множественных одновременных ошибок (максимум 1-2)

### reCAPTCHA
- [ ] reCAPTCHA виден на мобильной версии
- [ ] reCAPTCHA не перекрывает другие элементы
- [ ] Можно взаимодействовать с reCAPTCHA на мобильной версии
- [ ] После отметки reCAPTCHA она не исчезает
- [ ] reCAPTCHA работает после rotate экрана

## ✅ 3. ОТПРАВКА ФОРМЫ И ОБРАБОТКА ОШИБОК

### Успешная регистрация
- [ ] После заполнения формы и клика на "Sign Up":
  - [ ] Кнопка становится loading (спиннер или текст "Loading...")
  - [ ] Форма не позволяет повторную отправку (disabled)
  - [ ] Ждём ответа API (должно быть быстро, < 10 сек)
  - [ ] Успешное сообщение показывается
  - [ ] Редирект на `/auth/confirmation` или `/onboarding`

### Обработка ошибок регистрации
- [ ] **Email уже существует:**
  - [ ] Показывается понятное сообщение об ошибке
  - [ ] Ошибка на русском языке
  - [ ] Форма не закрывается, можно отредактировать email

- [ ] **Слабый пароль:**
  - [ ] Показывается требование к паролю
  - [ ] Сообщение объясняет минимальные требования

- [ ] **Сетевая ошибка:**
  - [ ] Показывается сообщение "Проверьте интернет"
  - [ ] Кнопка "Retry" позволяет переотправить форму

- [ ] **Слишком много попыток (Rate Limit):**
  - [ ] Показывается сообщение о временной блокировке
  - [ ] Указан таймер ожидания (если применимо)

- [ ] Страница загружается после регистрации/подтверждения email
- [ ] Видна прогресс-бар (1/4, 2/4 и т.д.)
- [ ] **Height поле:**
  - [ ] Input тип = number
  - [ ] Можно ввести высоту в см
  - [ ] Валидация если < 100 или > 300 см

- [ ] **Weight поле:**
  - [ ] Input тип = number
  - [ ] Можно ввести вес в кг
  - [ ] Валидация если < 30 или > 300 кг

- [ ] **Goals выбор:**

- [ ] **Навигация:**

  - [ ] Кнопка "Next" disabled если обязательные поля пусты

  - [ ] Text input'ы доступны для ввода

### Шаг 4: Complaints & Symptoms

  - [ ] Tried interventions

- [ ] Кнопка "+ Add another complaint" работает
- [ ] Можно удалить жалобу (if delete button present)

- [ ] **Макет:**
  - [ ] Нет горизонтального скролла

  - [ ] Все поля фокусируются при тапе
  - [ ] Клавиатура не перекрывает форму целиком
  - [ ] После ввода данных клавиатура скрывается
  - [ ] Tab navigation работает (if applicable)

- [ ] **Ориентация экрана:**
  - [ ] Форма работает в портрете (375x667)
  - [ ] Форма работает в ландшафте (667x375)
  - [ ] При rotate не теряются введённые данные
  - [ ] Макет адаптивен для обеих ориентаций
