## ✅ ЧЕКЛИСТ ВЁРСТКИ

### 🔴 КРИТИЧЕСКИЕ ПРОБЛЕМЫ (ДОЛЖНЫ БЫТЬ ИСПРАВЛЕНЫ)

Проверьте на каждой странице:

- [ ] **Нет горизонтального скролла**
  - Поворот экрана на портрет (395px)
  - Поворот экрана на ландшафт (667px)
  - ❌ Если есть горизонтальный скролл → BUG

- [ ] **Все кнопки полностью видны (не обрезаны)**
  - Кнопка не выходит за правый край экрана
  - Кнопка не выходит за левый край экрана
  - Текст кнопки полностью виден
  - ❌ Если текст обрезан → BUG

- [ ] **Все input поля полностью видны**
  - Input не выходит за края экрана
  - Можно ввести текст
  - ❌ Если input обрезан → BUG

- [ ] **Кнопки имеют правильный размер (>=44px)**
  - Нажимаешь на кнопку, она реагирует на первый тап
  - Нет нужности в повторном тапе или точечном попадании
  - ❌ Если кнопка микроскопическая → BUG

---

### 🟠 ВАЖНЫЕ ПРОБЛЕМЫ (НУЖНО ИСПРАВИТЬ)

- [ ] **Текст в кнопках не переполняется**
  - Текст вмещается в кнопку
  - Текст не обрезается (…)
  - Текст не "плывёт" или выходит за границы
  - ❌ Если "Sign up for free →" обрезан до "Sign u…" → BUG

- [ ] **Все элементы в форме выровнены**
  - Левый край всех input'ов на одной линии
  - Правый край всех input'ов на одной линии
  - Не "плывут" или сдвигаются случайно
  - ❌ Если input прыгает при фокусе → BUG

- [ ] **Нет элементов, выходящих за экран**
  - Модальные окна, карточки полностью на экране
  - Не нужно скролить влево-вправо, только вверх-вниз
  - ❌ Если dropdown выходит за экран → BUG

- [ ] **Иконки правильного размера**
  - Иконки в bottom bar кликабельны (>=44px)
  - Иконки в кнопках видны
  - ❌ Если иконка микроскопическая → BUG

---

### 🟡 КАЧЕСТВО (ЖЕЛАТЕЛЬНО ИСПРАВИТЬ)

- [ ] **Отступы (padding, margin) правильные**
  - Не слишком большие зазоры между элементами
  - Не слишком маленькие зазоры
  - Ощущается "дышащий" дизайн

- [ ] **Текст читаемый**
  - Размер шрифта достаточный (не менее 14px)
  - Контраст хороший (чёрный текст на белом фоне)
  - Не слишком плотно упакан

- [ ] **Анимации плавные**
  - Нет рывков при скролле
  - Нет зависания UI

## 🐛 ТИПИЧНЫЕ БАГИ ВЁРСТКИ

### Баги, которые часто встречаются:

❌ **"Плывущие" элементы**
- Кнопка прыгает при фокусе input (из-за появления клавиатуры)
- Элементы сдвигаются при scroll
- **Как исправить:** Использовать `position: fixed` и safe-area для bottom bar

❌ **Обрезанные кнопки**
- Текст "Sign up for free" обрезан до "Sign up for f…"
- Кнопка выходит за правый край экрана
- **Как исправить:** Добавить `overflow-x: auto` на body, использовать `max-width` для контейнеров

❌ **Горизонтальный скролл**
- Можно скролить влево-вправо на мобильной версии
- Обычно из-за элемента с фиксированной шириной > 100vw
- **Как исправить:** Удалить `width: 100vw`, использовать `width: 100%`

❌ **Микроскопические кнопки**
- Кнопка меньше 44x44px
- Нужно тапить с максимальной точностью
- **Как исправить:** Минимум `height: 44px` для button/a, `min-width: 44px`

❌ **Непочитаемый текст**
- Шрифт слишком маленький (< 14px)
- Низкий контраст (серый текст на белом)
- Текст плотно упакан без breathing room
- **Как исправить:** `font-size >= 14px`, `color-contrast >= 4.5:1`, `line-height >= 1.5`
