Partner API Brief

VITALOOP B2B Analyze Labs API

Controlled-pilot API for external platforms that need structured blood test analysis.

What VITALOOP Provides

A partner platform sends parsed blood test biomarkers as JSON. VITALOOP normalizes the data, applies its knowledge base, rules, safety evaluation, AI/fallback protocol generation, and returns a structured analysis result the partner can render inside its own product.

Partner platform -> VITALOOP API -> Structured blood analysis -> Partner platform

Endpoint

POST /v1/b2b/analyze-labs

Input

  • Partner-scoped external_user_id
  • Biomarker list as JSON
  • Optional symptoms and questionnaire data
  • Optional safe integration metadata

Output

  • Health summary and prioritized biomarkers
  • Risks and safety flags
  • Recommendations and protocol sections
  • Retest suggestions and doctor summary
  • Medical disclaimer and analysis metadata

Security

  • API key authentication via X-Partner-Api-Key
  • Required scope: labs:analyze
  • Tenant isolation by resolved partner key
  • Redis-backed rate limits by partner and API key
  • Optional IP allowlist and Cloudflare WAF for public launch
  • Idempotency via X-Idempotency-Key

PHI/GDPR Notes

  • Use opaque external user IDs where possible.
  • Avoid unnecessary PHI in metadata.
  • Raw payload storage is minimized during the pilot.
  • Retention is partner-configurable.
  • Export/delete is operator-run during the pilot.

Pilot Readiness

Suitable for a controlled pilot with 1-2 trusted partners after staging deployment, SQL migration, Redis rate limit configuration, Cloudflare rules, one test partner key, and smoke testing.
