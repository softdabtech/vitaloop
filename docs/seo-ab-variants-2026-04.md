## Test Rules

- Run one variant at a time per page for clean attribution.
- Minimum duration per variant: 14 days.
- Keep H1 and on-page primary CTA unchanged during each variant run.

## Primary Metrics

- Google Search Console CTR (page-level)
- Impressions (to ensure enough sample)
- Signup conversion rate from organic sessions (GA4)

## Launch Sequence

1. Home Variant B for 14 days.
2. Home Variant C for 14 days.
3. Keep winner. Repeat same sequence for /how-it-works.

## Rollback

If CTR drops by >15% vs control after 7 days with stable impressions, revert to control immediately.
